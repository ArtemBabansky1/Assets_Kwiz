## UTM в заявках квиза

`kwiz.js` передаёт `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`,
`utm_content`, `utm_id` отдельными полями FormData на `/quiz-form` и `/quiz-gift`.
Метки считываются при загрузке и отправке формы. Сохраняются в sessionStorage
в пределах вкладки; новый URL с метками заменяет всю предыдущую кампанию.
Если storage недоступен, значения сохраняются в памяти. Пустые поля не отправляются.

Проверка: `node --test tests/utm.test.cjs` (сетевые запросы перехватываются,
тестовые контакты в HubSpot не создаются).

Бэкенд `tumodo.io` отсутствует в этом репозитории. Для полной интеграции обработчик
`/quiz-form` должен принимать эти поля и включать их в свойства контакта/отправку
формы HubSpot с соответствующими внутренними именами свойств.

После публикации исправленного `kwiz.js` обновите URL скрипта в Tilda T123 на новый
commit SHA. Загрузчик с предыдущим SHA продолжит загружать старую версию.
